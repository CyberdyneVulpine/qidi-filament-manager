Filament manager

QIDI touchscreen catalog

Add, edit, and remove materials in the load menu. New rows are copies of a material already on this printer. The touchscreen reads the catalog when it starts.

This printer's touchscreen does not use that catalog.

Apply changes restarts Klipper's firmware, then the touchscreen, so both read the catalog again. Use it after any add, edit, removal, or restore. Klipper keeps its own copy of the list, and selecting a material it does not know shuts it down. Restart touchscreen only reloads the screen, and is blocked while Klipper has an older copy. Reboot printer restarts the whole machine.

Rows marked Added here were not in the file the first time this manager ran on this printer. Rows marked In use are selected on a slot. Choose another material for that slot on the touchscreen before removing one or changing its id.
